# 📖 Paper Evaluation Using AI

## Overview

Paper Evaluation Using AI is an intelligent automated answer sheet evaluation system designed to assess handwritten or digital student responses using Artificial Intelligence, Machine Learning, Optical Character Recognition (OCR), and Natural Language Processing (NLP).

The system extracts text from answer sheets, processes and analyzes the content, compares it with model answers, and generates evaluation scores automatically. This helps reduce manual grading effort, improve consistency, and accelerate the assessment process.

---

## Problem Statement

Traditional answer sheet evaluation is time-consuming, labor-intensive, and prone to human bias. Educational institutions require a scalable solution that can evaluate student responses efficiently while maintaining fairness and accuracy.

This project addresses these challenges by leveraging AI-driven text extraction and semantic similarity techniques for automated assessment.

## Project Workflow

### Step 1: OCR Processing

The system extracts textual content from handwritten answer sheets using OCR technology.

### Step 2: Text Preprocessing

Extracted text is cleaned and normalized through:

* Tokenization
* Stop-word removal
* Text normalization

### Step 3: Feature Extraction

TF-IDF vectorization converts textual data into numerical feature vectors.

### Step 4: Similarity Analysis

Cosine Similarity is used to compare student answers with reference answers.

### Step 5: Evaluation and Scoring

KNN algorithm assists in determining the final score based on similarity measures.
